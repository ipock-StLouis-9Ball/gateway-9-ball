# Enterprise Architecture Specification: Gateway 9-Ball (GCP High-Concurrency & Scalability)

## 1. Executive Summary & Vision
Gateway 9-Ball is a real-time, skill-based 9-ball pool game engineered to support **thousands of concurrent players per day**. Built with a **client-server authoritative model**, the game guarantees 100% cheat-proof physics and financial integrity while maintaining ultra-low latency.

75%+ of profits generated by the Gateway 9-Ball platform are dedicated to funding housing initiatives for veterans and disabled individuals experiencing homelessness.

## 3. Core Component Roles

### 3.1 Client Layer (`js/`)
- **Technology**: Vanilla JS ES Modules, HTML5 2D Canvas Renderer (`renderer.js`).
- **Function**: Renders table felt, pocket cutouts, ball positions, ghost aiming trajectory lines, and HUD controls.
- **Security Rule**: The client never computes wagers, fouls, or ball final positions authoritatively. It captures input (angle, power, english) and sends it to the server.

### 3.2 Authoritative Game Server (`server/`)
- **Technology**: TypeScript, Express, WebSockets, Shared ES Module Physics (`js/physics.js` & `js/rules.js`).
- **Function**: Resolves shot trajectories deterministically, detects pocket drops, applies APA 9-ball rules (ball-in-hand, lowest ball first, 9-ball respot on foul), tracks set scores (best of 3), and handles 90s forfeit windows.

### 3.3 Financial Ledger & Escrow (`server/services/`)
- **Ledger System**: Double-entry accounting system (`ledgerService.ts`). Every buy-in, win payout, and withdrawal has balanced debit and credit entries.
- **Escrow Vault**: Holds player wager funds during gameplay until one player reaches 2 set wins.
- **Platform Fee**: Collects house rake (8-12% tiered buy-in model).

### 3.4 Resilient AI Sentinel & Support Agents (`server/services/supportHub.ts`)
- **Agent Zeta (Concierge)**: Answers player queries regarding rules, wallet, and store items.
- **Agent Eta (Resolver)**: Resolves escalated dispute tickets.
- **Resilience Guardrails**: Implements strict repetition loop detection, context truncation (max 10 turns), rate-limiting, and deterministic fallbacks to guarantee AI agents never lock up or enter infinite loops.

## 4. Google Cloud Platform (GCP) Infrastructure Scaling

1. **Google Kubernetes Engine (GKE) / Cloud Run**: Auto-scales containerized shot resolver instances based on CPU utilization and incoming WebSocket connections.
2. **Cloud Spanner / BigQuery**: High-concurrency persistent SQL database for user accounts, transaction logs, and regulatory telemetry.
3. **Cloud Load Balancing & VPC Network**: Global HTTP(S) and WebSocket load balancing providing ultra-low ping match routing.
4. **Cloud Armor & Security Sentinel**: Prevents DDoS attacks and lag-switch manipulation during real-money wager matches.

---

## 5. Summary of Eliminated Overhead
To maximize profitability, reliability, and low-latency performance:
- **No IoT/Helium/IoTeX Bloat**: Pure digital architecture without unnecessary hardware dependencies.
- **No Akash/Flux Decentralized Compute Latency**: Dedicated GKE/Cloud Run infrastructure ensures sub-50ms round-trip times for competitive PvP.
- **No Unnecessary Asset Lag**: SVG visual assets served via global Cloudflare/Cloud CDN.
